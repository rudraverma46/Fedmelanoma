# FedMelanoma

A research implementation of **FedMelanoma**, a federated learning framework for melanoma classification.

## Features

- Flower-based Federated Learning
- Boltzmann Client Selection
- Reliability-aware Client Scheduling
- Optimal Transport Diversity Prior
- Adaptive Straggler Handling
- Class-weighted Focal Loss
- EfficientNet-B3 + Metadata Fusion
