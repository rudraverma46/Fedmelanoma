# resnet50_fedlesscan_novelty_env: documentation

FedLesScan (official-code rules) with ResNet-50 on the FedMelanoma hospital partitions, in the Novelty straggler environment. None of the Novelty method is used. 6 clients per round, 5 local epochs, 50 rounds, seed 42.

Run ID: `resnet50-fedlesscan-novelty-env-seed42`. Status: completed, 50 rounds, 243 updates aggregated, evaluated.
