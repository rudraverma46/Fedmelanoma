# resnet_50_fedstrag_final: documentation

Standard FedStrag with ResNet-50 on the FedMelanoma hospital partitions, in the Novelty straggler and failure environment, starting from the Novelty run's exact initial weights. None of the Novelty method is used. All 10 hospitals per broadcast, 4 s poll, W x D weighting, 5 local epochs, 50 global iterations, seed 42.

Run ID: `resnet50-fedstrag-final-seed42`. Status: completed in one attempt on an H100 (2026-11-20 01:07 UTC to 2026-11-20 02:51 UTC), 208 updates applied, evaluated.
